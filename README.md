# Python-Day-161-CSV-Data-Cleaner
# CSV Data Cleaning & Validation System – Python Day 161

## Description
A Python application that cleans raw student data stored in CSV format by validating records and removing invalid or duplicate entries.

## Features
- Reads raw CSV data
- Validates student IDs and email addresses
- Checks age and marks ranges
- Detects duplicate IDs
- Generates cleaned and rejected CSV files
- Displays a data cleaning report

## Technologies
- Python
- CSV Module
- Regular Expressions

## Files
- `data_cleaner.py`
- `students_raw.csv`
- `cleaned_students.csv` – generated automatically
- `rejected_students.csv` – generated automatically

## How to Run
```bash
python data_cleaner.py
```

## Concepts Used
CSV Processing, Data Validation, Regular Expressions, Sets, File Handling and Exception Handling.
